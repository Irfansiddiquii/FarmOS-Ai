# 🌾 Overview

FarmOS AI is an intelligent agriculture operating system designed to help farmers make smarter decisions using Artificial Intelligence.

The platform combines AI diagnostics, weather intelligence, crop analytics, government schemes, farm management, marketplace integration, and real-time insights into a single modern dashboard.

Rather than acting as a simple farming website, FarmOS AI functions as a complete digital ecosystem for precision agriculture.

- # ⚙️ Installation

Follow these steps to run FarmOS AI on your local machine.

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Irfansiddiquii/FarmOS-Ai.git
```

---

## 2️⃣ Navigate to Project

```bash
cd FarmOS-Ai
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Configure Environment Variables

Create a file named

```text
.env.local
```

Copy the following variables.

```env
NEXT_PUBLIC_SUPABASE_URL=

NEXT_PUBLIC_SUPABASE_ANON_KEY=

SUPABASE_SERVICE_ROLE_KEY=

GEMINI_API_KEY=

NEXTAUTH_SECRET=
```

Fill all values before running the project.

---

## 5️⃣ Start Development Server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

# 🚀 Production Build

```bash
npm run build
```

Run Production

```bash
npm start
```
